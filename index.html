LOCAL FIRST. NOT LOCAL ONLY IN NAME.

你的项目，不必搬家。

Cox 的控制服务运行在你的电脑上，默认只监听回环地址。项目、会话历史、凭据和检查点保存在本地 Cox 数据目录，而不是 Cox 云端账号里。

无需 Cox 云端账号保留本地认证MIT 开源

本地优先不代表离线推理：智能体仍会调用你配置的模型服务，Git 集成也可能访问对应的代码托管平台。

完整使用说明↗
>_终端Node.js 26.12.1

# 无需全局安装，直接运行

npx @doublepi123/cox@latest

# 也可以全局安装

npm install --global @doublepi123/cox@latest
cox
启动后，打开终端打印的本地地址。
  1. 01

    运行 Cox

    使用 Node.js 26.12.1，运行启动命令，按终端提示打开本地 Web 界面。

  2. 02

    连接你的智能体

    在设置中配置 Provider。CLI 型智能体需要在本机安装并完成认证；也可配置支持的 API 网关。

  3. 03

    选一个项目，开始构建

    添加本地项目目录，创建会话，选择模型。剩下的，从你的第一个想法开始。

Cox 不包含模型订阅或 API 额度。请使用自己的账号与凭据；如原生依赖没有预编译版本，安装时可能需要 C/C++ 构建工具。
