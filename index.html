02Cox Desktop

不开终端，也有你的本地工作台

macOS 与 Windows 桌面客户端，内置独立 Node 运行时和仅限回环地址的本地后端。下载、打开，然后继续你的工作。

下载桌面版 macOS Apple Silicon / Intel · Windows x64

智能体 CLI、账号认证和模型订阅仍需单独配置。发布签名与平台验收说明见 Release。

打开就用，无需先装 Node

内置界面、Node 运行时与本地后端；桌面数据与 CLI 分开保存，不影响现有工作区。

更新不中断当前任务

更新下载后在下次正常启动时生效。激活前备份数据，失败时恢复旧后端及对应数据快照。

桌面体验，仍然本地

保留本地认证与 Origin 校验，后端只监听 127.0.0.1；macOS 关闭窗口后，任务继续运行。

03本地优先，不是云端托管

你的项目，不必搬家

Cox 服务运行在你的电脑上，默认只监听本机回环地址。项目、对话、凭据与检查点，留在你的本地数据目录。

  • 无需注册 Cox 云端账号
  • 本地认证保护你的工作台
  • MIT 开源，代码可审计

本地优先不等于离线推理：智能体仍会调用你配置的模型服务，Git 集成也可能访问相应的代码托管平台。

05也可以用命令行

一条命令，开始构建

无需克隆仓库，也不用安装开发依赖。npm 包已包含构建好的界面与本地服务。

  1. 01

    运行 Cox

    在终端运行启动命令。如果浏览器没有自动打开，按终端提示访问本地地址。

  2. 02

    连接智能体

    在设置中添加智能体。CLI 型智能体需在本机安装并完成登录；也可以配置受支持的 API 网关。

  3. 03

    打开项目，开始构建

    添加本地项目目录，新建对话并选择模型，然后说出你的第一个想法。

完整使用说明
终端Node.js 26.12.1

# 直接运行最新版本

$ npx @doublepi123/cox@latest

# 或者全局安装

$ npm install --global @doublepi123/cox@latest
$ cox

Cox 会启动仅限本机访问的服务，并自动打开浏览器。

Cox 不包含模型订阅或 API 额度，请使用你自己的账号与凭据。如果原生依赖没有适用于你平台的预编译版本，安装时可能需要 C/C++ 构建工具。
