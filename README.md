# Cox

The product homepage for [Cox](https://github.com/doublepi123/cox), a local Web workspace for coding agents.

**Website: https://doublepi123.github.io/**

This repository contains only the public, bilingual static website. It does not host coding agents, user projects, credentials, or the Cox local server. The interactive workspace is an illustration, not a live agent connection.

## Publishing

GitHub Pages publishes the root of the `master` branch. Keep `.nojekyll` and the relative asset paths. The `cox/index.html` compatibility page redirects the previously shared /cox/ address to the homepage.

The previous personal homepage has been replaced; its contents remain in Git history for rollback.
